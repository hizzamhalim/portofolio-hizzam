2. Buka folder `portofolio_hizzam_flutter` di Android Studio atau VS Code.

## Cara membuat APK
Jalankan perintah:
`flutter build apk --release`

File APK akan berada di:
`build/app/outputs/flutter-apk/app-release.apk`

Sebelum dikumpulkan, ganti nama APK sesuai instruksi dosen, misalnya:
